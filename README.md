## Introduction

The `Facebook-Business-Manager-Admin-Tool` is a powerful, lightweight, and easy-to-use JavaScript tool for efficient Facebook Business Manager admin management and control. It provides a simple interface to manage multiple admins, remove users, and monitor Business Manager activities without requiring complex setup or advanced knowledge of Facebook's Business Manager API.

## Benefits

🚀 **Easy Admin Management:** Provides automated methods to view, manage, and remove Facebook Business Manager admins in bulk.

⚡ **Automatic UI Updates:** The interface refreshes automatically when admins are added, removed, or status changes occur.

🎮 **Simple and User-Friendly:** Does not require knowledge of complex Facebook API solutions or Business Manager setup.

🔧 **Multiple API Support:** Supports both Facebook Graph API and Business Manager API endpoints.

🌍 **Multi-Status Support:** Manage admins with different statuses (CONFIRMED, PENDING, Full Control, Partial Access).

## Features

### 🔍 **Advanced Search & Filter**
- Search admins by name or email
- Filter by status (All, CONFIRMED, PENDING)
- Real-time search with instant results

### 👥 **Admin Management**
- View all Business Manager admins
- Remove multiple admins at once
- Remove yourself from Business Manager
- Check admin roles and permissions

### 📊 **Data Visualization**
- Sortable table with admin information
- Last active time tracking
- Role and permission display
- User type identification

### 🎨 **User Interface**
- Draggable popup window
- Modern, responsive design
- Keyboard shortcuts support
- Real-time status updates

## Installation

1. **Download the tool:**
   ```bash
   git clone https://github.com/yourusername/facebook-bm-admin-tool.git
   cd facebook-bm-admin-tool
   ```

2. **Open in Facebook Business Manager:**
   - Navigate to your Facebook Business Manager
   - Open browser console (F12)
   - Paste the `index.js` content
   - Press Enter to execute

## Usage

### Basic Usage

1. **Access the Tool:**
   - Go to Facebook Business Manager
   - Open browser console (F12)
   - Run the script
   - The admin tool popup will appear

2. **Search Admins:**
   - Use the search box to find specific admins
   - Filter by status using the dropdown
   - Results update in real-time

3. **Manage Admins:**
   - Select admins using checkboxes
   - Use "Select All" for bulk operations
   - Click "Delete Selected Admins" to remove

### Keyboard Shortcuts

- `Ctrl + F` or `/` - Focus search box
- `Ctrl + B` - Search BM by ID
- `Ctrl + R` - Refresh data
- `Ctrl + A` - Select all admins
- `Esc` - Close panel

## API Endpoints

The tool uses Facebook Graph API endpoints:

- **Get Admins:** `https://graph.facebook.com/graphql`
- **Remove Admin:** `https://graph.facebook.com/v18.0/`
- **Cancel Invite:** Business Manager API
